# Luxora Studio

**Imagine it. Create it. Bring it to life.**

AI-powered image and video creation studio for web and Android.

## Product requirements

- Dark-luxury, mobile-first experience for Chrome on Android.
- Android app package: `com.luxorastudio.app`.
- Real AI image and video generation, with configurable settings, previews, exports, progress, retries, and project history.
- Secure accounts and private project storage before production use.
- Free-first operation. Do not activate payments or paid services without explicit approval.
- A feature is complete only after implementation and testing; demo behavior must never be described as real AI generation.

## Current status

This repository has been created. The real generation backend, authentication, private storage, and production deployment are **not yet implemented or verified**. Do not treat the product as production-ready until these requirements are built and tested.

## Deployment

GitHub Pages can host a static frontend, but it cannot run the AI generation backend by itself. Real image/video generation requires a compatible model runtime or provider and server-side integration. Keep provider credentials out of browser code and the repository.
